# Привязка QR экземпляров

Страница, которая помогает заполнить шаблон «Состав грузомест» из заявки на поставку: сканируете товар и QR-коды его экземпляров, страница проверяет ошибки и отдаёт готовый файл для загрузки в личный кабинет.

**Открыть страницу:** https://nickylast.github.io/qr-privyazka/

## Как пользоваться

1. Скачайте в заявке шаблон «Состав грузомест» и перетащите его на страницу.
2. Сканируйте штрихкод товара, затем QR-коды всех его экземпляров. Если коробок несколько, перед товарами сканируйте штрихкод коробки.
3. Нажмите «Скачать файл» и загрузите его в заявку.

Подходит любой USB-сканер, который работает как клавиатура и отправляет Enter после кода.

## Что проверяется

- повторы: та же этикетка второй раз или этикетка, уже привязанная к другому товару;
- лишние экземпляры сверх количества в шаблоне и товары или коробки не из этой поставки;
- русская раскладка («шш» вместо «ii»), Caps Lock и пробелы исправляются автоматически;
- коды, которые уже были в прошлых поставках (архив хранится в браузере).

## Работа без интернета и на другом компьютере

Вся страница — один файл `index.html`. Откройте ссылку выше и сохраните страницу (Ctrl+S) или скачайте `index.html` из этого репозитория: файл открывается двойным щелчком в любом браузере и работает без интернета.

## Данные

Файлы обрабатываются прямо в браузере и никуда не отправляются. Незаконченное сканирование и архив кодов хранятся только в браузере на том компьютере, где вы работаете.

Для чтения Excel в страницу встроена библиотека [JSZip](https://stuk.github.io/jszip/) 3.10.1 (лицензия MIT).
